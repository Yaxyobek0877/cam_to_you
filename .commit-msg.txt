fix(v0.1.6): CRITICAL bug - missing -map 0:v broke stream startup

Root cause: builder.go's buildSingleArgs didn't add -map 0:v for video.
buildAudioArgs adds -map 0:a? for audio. When ffmpeg sees ANY -map flag,
it disables automatic stream selection. Result: stream contained ONLY
audio (or failed completely if video was needed), explaining why
"Start" button would spin and exit immediately.

Verified fix by running corrected ffmpeg command against real Hikvision
camera (192.168.200.5) - produces valid 2 MB FLV in 5 seconds.
