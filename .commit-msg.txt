fix(v0.1.12): auto-restart on clean exit + stability flags

Progress from v0.1.11: stream connects, briefly appears on YouTube,
then stops after ~10 seconds. Logs show:

  Holat: running (15:24:52)
  swscaler warning (15:24:57)
  Holat: stopped (15:25:03)

BUG 1: manager.go didn't restart on clean exit
- When FFmpeg exits with code 0, runner sets state = StateStopped
- Manager treated StateStopped == "user requested stop" → no restart
- But user didn't stop — FFmpeg exited on its own (likely YouTube drop
  or RTSP hiccup)

Fix: differentiate user-stop (ctx.Done branch) from runner-exit
(runner.Done branch). If we reach the post-select code, user didn't
stop. Always restart if AutoRestart=true, regardless of exit code.

BUG 2: pixel format warning (yuvj420p → yuv420p conversion)
- Hikvision sends yuvj420p (JPEG full-range)
- YouTube wants yuv420p (TV-range)
- FFmpeg auto-converts but warns "make sure range is correct"

Partial fix: -pix_fmt yuv420p added to ALL encoders (NVENC, QSV,
AMF, x264, OpenH264). Was only in x264 before.

NEW: pipeline robustness flags
- -fflags +genpts+discardcorrupt: regenerate PTS, drop corrupt
  packets (helps with flaky RTSP)
- -flush_packets 1: send packets immediately, smaller buffer

NEW: -profile:v high added to QSV and AMF (was missing)
NEW: -bf 0 added to AMF (no B-frames for live)
