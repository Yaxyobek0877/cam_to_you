## 🚨 Visual ogohlantirish — stream key noto'g'ri

Bazada hali ham eski **`live2`** stream key saqlangan. Migration uni topa olmadi (chunki "live2" boshida `rtmp` yo'q). Endi muammoni darrov ko'rasiz va tuzatasiz:

### Yangi ko'rinish

Stream kartasida endi:

| Holat | Tugma |
|-------|-------|
| ✅ Key to'g'ri | **▶ Ishga tushirish** (yashil) |
| ⚠ Key noto'g'ri | **✏ Key kiriting** (sariq) |

Va sarlavha yonida **`⚠ Key noto'g'ri`** badge ko'rinadi.

### Start qachon bosilsa

Agar key noto'g'ri bo'lsa, **FFmpeg umuman ishga tushirilmaydi**. Buning o'rniga aniq xato:

> "live2 — bu YouTube serverining yo'l qismi, stream key emas. YouTube Studio → Go Live → Stream key qismidan key'ni nusxalang va stream'ni tahrirlab kiriting"

## ✅ Sizga endi nima qilish kerak

[v0.1.10 yuklab oling](../../releases/download/v0.1.10/cam_to_you.exe).

1. **Streams** sahifa → "kirish" stream
2. Endi siz **"Key kiriting"** sariq tugma ko'rasiz (Start emas)
3. Tugmani bosing → tahrirlash formasi ochiladi
4. Stream Key maydonini **bo'shating** (eski "live2" ni o'chiring)
5. **YouTube Studio** → studio.youtube.com → profilingiz → Create → **Go live** → Stream key 🔑
6. **COPY** tugmasini bosib, Cam2You formaga paste qiling
7. ✅ Yashil tasdiqlash chiqishi kerak — "Stream key formati to'g'ri ko'rinmoqda"
8. **Saqlash**
9. Endi stream kartasida **▶ Ishga tushirish** tugmasi ko'rinadi
10. **Bosing** → 30-60 sek ichida YouTube'da live ko'rinadi

**Muhim:** Stream key formati `xxxx-xxxx-xxxx-xxxx-xxxx` — **5 ta guruh, 24 belgi**. Hech qanday `rtmp://` qismsiz.
