## 🔄 Auto-restart endi har qanday holatda ishlaydi

### Sizning oxirgi log

```
15:24:52  Holat: running
15:24:57  [swscaler] deprecated pixel format used
15:25:03  Holat: stopped
```

11 sekund ishladi, **YouTube'da bir marta ko'rindi** (siz aytgan "lekin orada bir marta korinsin"), keyin to'xtab qoldi. **Lekin AutoRestart ishlamadi** — chunki bizning kodda "stopped" holatini foydalanuvchi to'xtatish deb tushunardi.

### Tuzatish

```diff
- // Normal chiqdimi yoki xato bilanmi?
- if finalState == ffmpeg.StateStopped {
-     return // foydalanuvchi to'xtatdi (NOTO'G'RI!)
- }
+ // Bu joyga yetishimiz uchun: foydalanuvchi to'xtatmagan.
+ // FFmpeg o'zi chiqdi (xato yoki toza). AutoRestart bo'lsa qayta urinamiz.
```

Endi:
- **Toza chiqish** (exit 0) → restart
- **Xato bilan chiqish** → restart
- **Faqat foydalanuvchi Stop bossa** → restart yo'q

## 🛠 Pipeline barqarorligi

Yangi flaglar barcha encoderlar uchun:
```
-pix_fmt yuv420p         ← YouTube formati (oldin faqat x264'da edi)
-fflags +genpts+discardcorrupt  ← korrupt paketlarni tashlash
-flush_packets 1         ← darrov yuborish, kichik buferlash
-profile:v high          ← QSV, AMF uchun ham qo'shildi
-bf 0                    ← B-frames yo'q (live barqarorroq)
```

## ✅ Endi nima bo'lishi kerak

1. Stream ishga tushadi
2. YouTube'da ko'rinadi (30-60 sek)
3. **Agar biror sabab bilan to'xtab qolsa** (network, YouTube hiccup), 5 sekunddan keyin **avtomatik qayta urinadi**
4. AutoRestart cheksiz urinadi (sizning konfiguratsiyada `max_restarts: 0` = cheksiz)

Sizning kameradan stream **uzluksiz** YouTube'ga uzatiladigan bo'lishi kerak. Birinchi 30-60 sek YouTube Studio'da preview ko'rinadi, keyin **doimiy live oqim**.
