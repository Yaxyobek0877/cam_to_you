## 🎯 RTSP barqarorligi va aniq tavsiyalar

v0.1.16'da diagnostika ko'rsatildi — endi nima sababdan uzilayotgani **aniq**: Hikvision kamerasi har 7-8 sekundda RTSP sessiyani yopayapti (`Failed reading RTSP data: End of file`).

v0.1.17 bu muammoni **uch tomondan** hal qilishga harakat qiladi:

## ✅ Yangi xususiyatlar

### 1. RTSP stabillik bayroqlari

Endi har bir RTSP ulanishida quyidagi qo'shimchalar:

| Bayroq | Qiymat | Maqsad |
|--------|--------|--------|
| `-stimeout` | 10 sek | RTSP socket timeout — kamera 10s'gacha javob bermasa, FFmpeg uziladi (cheksiz kutish o'rniga) |
| `-rw_timeout` | 10 sek | Read/write timeout |
| `-reorder_queue_size` | 0 | RTSP paket buferi minimum — kameraga aktiv signal yuboradi |
| `-fflags` | `+nobuffer+discardcorrupt` | Darrov o'qish, buzuq paketlarni tashlash |
| `-probesize` | 32 | Kichik probe — tezroq ulanish |
| `-analyzeduration` | 1 sek | Qisqa analiz — frame'lar darrov o'qiladi |

### 2. Restart kechikishi 3 sekundga ko'tarildi

Kamera RTSP sessiyani yopgandan keyin, bo'shatish uchun **2-3 sek vaqt kerak**. Avval 1 sek edi — bu yangi ulanishni eski sessiya qoldig'iga ulardi. Endi:

- 1-10 urinish: 3 sek delay
- 11+ urinish: exponential (3→6→12→...→5 min)

### 3. Aniq tavsiyalar tizimi

Endi har stream uzilganida, log analiz qilinadi va foydalanuvchiga **aniq tavsiya** beriladi:

```
🔍 FFmpeg chiqdi (exit=0, state=stopped). Oxirgi qatorlar:
🎥 Kamera RTSP sessiyani yopdi (EOF). Bu odatda Hikvision sessiya cheklovi.
   YECHIM: kamera web UI → Configuration → Video/Audio → Sub Stream → 
   Video Encoding'ni H.264 ga o'zgartiring (H.265 dan).
   Keyin Cam2You'da Encoder = Copy tanlang.
  └ [in#0/rtsp @ ...] Failed reading RTSP data: End of file
  └ frame=1 fps=0.0 q=36.0 ...
```

**Aniqlangan xato patternlari:**
- 🎥 RTSP EOF → kamera sessiya cheklovi
- 🔐 401 Unauthorized → login/parol xato
- 🌐 Connection refused → IP/port xato
- 🔌 Connection reset → tarmoq muammosi
- 📡 RTMP I/O error → stream key xato
- 💔 Broken pipe → RTMP duplicate
- 🎮 NVENC session limit → GPU band

## 🛠 Foydalanuvchiga qo'llanma

Agar shu yangi versiya bilan ham uzulish davom etsa, **kamera tomonda sozlama kerak**:

1. Brauzerda kamerani oching: `http://192.168.X.X`
2. **Configuration** → **Video/Audio** → 
3. **"Stream Type"** dropdown'iga bosing va **"Sub Stream"** ni tanlang ⚠️ (Main Stream'da emas!)
4. **Video Encoding**: H.265 dan **H.264** ga o'zgartiring
5. **Save** tugmasini bosing
6. Cam2You'da Encoder: **Copy** tanlang
