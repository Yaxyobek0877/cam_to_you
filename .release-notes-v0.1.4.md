## 🪟 Asosiy fix: Qora CMD oynalari yo'qotildi!

Sizning screenshot'ingizdagi qora oyna **FFmpeg subprocess'i ochgan CMD oynasi** edi. Go standartda Windows'da child process CMD oynasini ochishi mumkin (GUI dasturlarda bu istalmas).

**Yechim:** Har bir subprocess (`ffmpeg.exe`, `ffprobe.exe`) endi `CREATE_NO_WINDOW` + `HideWindow` flagi bilan ishga tushiriladi. Hech qanday CMD oynasi ko'rinmaydi.

## 🎬 Preview tuzatishi: manifestLoadError yo'qotildi

**Muammo:** UI 1.5 sekund kutib, `hls.js`'ga m3u8 yuklashga buyruq berardi. Lekin FFmpeg kameraga ulanib, encoding qilib, m3u8 yozish uchun 3-5 sekund kerak. Natija: `manifestLoadError`.

**Yechim:**
- 1.5 sek fixed timer **olib tashlandi**
- Endi UI **backend'dan "ready" hodisasini kutadi** (m3u8 fayli haqiqatda paydo bo'lganda yuboriladi)
- HLS player faqat fayl tayyor bo'lganda ishga tushiriladi
- Har xil kamera tezliklarida barqaror ishlaydi
