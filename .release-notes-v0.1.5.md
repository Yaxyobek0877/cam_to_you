## 💪 GPU yo'q kompyuterlar uchun yaxshilanish

Ko'p foydalanuvchilarda **GPU yo'q** — Cam2You ularda ham qulay ishlashi kerak.

### 📺 Preview avtomatik moslashadi

| Tizim | Preview rezolyutsiyasi | Sabab |
|-------|----------------------|-------|
| 🚀 GPU (NVIDIA/Intel/AMD) | **720p** | GPU oson ko'taradi |
| 💻 Faqat CPU | **480p** | Eski PC'larda ham silliq ishlaydi |

### 🎬 Hardware decode (HEVC uchun)

Yangi: `-hwaccel auto` — Hikvision'ning **HEVC** oqimini **har qanday GPU bilan dekodlash** (NVIDIA, AMD, Intel iGPU, hatto eski integrated graphics). Bu **CPU yukini kamaytiradi** — encoding qism GPU'siz bo'lsa ham yengilroq.

Hech qanday GPU yo'q bo'lsa, FFmpeg avtomatik software decode'ga qaytadi.

### 📊 Dashboard'da yangi "Tizim holati" karta

Kompyuteringizda nima mavjudligini ko'rsatadi:
- ✅ NVIDIA NVENC
- ✅ Intel QuickSync
- ✅ AMD AMF
- ✅ libx264 (CPU sifatli)
- ✅ libopenh264 (CPU fallback)
- ✅ Windows MediaFoundation

Plus: **moslashtirilgan tavsiya** sizning tizimingiz uchun.

### 💡 Stream formada aqlli maslahat

GPU yo'q bo'lsa, forma yangi karta ko'rsatadi:

> ⚠️ **GPU yo'q — CPU bilan ishlash**
> - 720p tavsiya etiladi (1080p CPU'ni qiyinlatadi)
> - Encoder: "Copy" tanlasa, hech qanday encoding kerakmas (eng yengil)
> - Kameralarda "Sub-stream" yoqsangiz, kamera o'zi 720p H.264 yuboradi
>   → **Copy + Sub-stream = ideal kombinatsiya** zaif PC uchun

Bonus: encoder ro'yxati endi **faqat mavjudlarni** ko'rsatadi (yo'q encoderni tanlash imkonsiz).

## 🧠 Eng yaxshi konfiguratsiyalar

### GPU bor (sizning RTX 3060 kabi)
```
Encoder:    Auto (NVENC tanlanadi)
Sifat:      1080p30 yoki 1080p60
Sub-stream: O'chirilgan (main stream — yuqori sifat)
```

### GPU yo'q (oddiy CPU)
```
Encoder:    Copy (qayta kodlamaslik)
Sifat:      Kamera nima yuborsa shu
Sub-stream: Yoqilgan (kamera o'zi 720p H.264 yuboradi)
```
Bu kombinatsiya: **deyarli 0% CPU ishlatadi**, har qanday eski PC'da ishlaydi.
