## 🔍 Xato sababini ko'rsatuvchi v0.1.7

### Muammo

Oldin: `⚠ Ishga tushmadi: exit status 0xffffffffb` — bu **nima xato bo'lganini ko'rsatmaydi**. Faqat raqam.

### Yechim

Endi har bir stream xatosi **3 ta narsa ko'rsatadi**:

1. **Qisqacha sabab** (birinchi qator)
2. **"Batafsil ko'rsatish"** tugmasi — FFmpeg'ning so'nggi log qatorlari (monospace)
3. **"Loglarni ko'rish"** — to'liq log oqimiga o'tadi

Misol — ilgari ko'rardingiz:
> ⚠ Ishga tushmadi: exit status 0xffffffffb

Endi shunday bo'ladi:
> ⚠ exit status 1
> 
> FFmpeg chiqishi:
> • Server returned 403 Forbidden  
> • Output URL #0 connection failed: rtmp://a.rtmp.youtube.com/live2/...
> • Could not write header for output file
>
> [Batafsil ko'rsatish] [📜 Loglarni ko'rish]

Endi siz darrov bilasiz — masalan, **stream key noto'g'ri** (403 Forbidden) yoki **NVENC ishlamadi** yoki **internet uzilgan**.

### Texnik o'zgarishlar

- **builder.go:** `-loglevel warning` → `-loglevel info` — ko'proq diagnostik ma'lumot to'planadi
- **runner.go:** yangi `enrichError()` funksiya — chiqish kodiga FFmpeg'ning so'nggi 8 ta error/warning qatori qo'shiladi
- **Streams.tsx:** yangi `ErrorBlock` komponent — ko'p qatorli xatoni tartibli ko'rsatadi

## 🧪 Sizning vaziyatingiz uchun

Yangi [v0.1.7 yuklab](../../releases/download/v0.1.7/cam_to_you.exe) oling va qayta sinab ko'ring.

Stream "Ishga tushirish" bosing → **endi aniq sabab ko'rinadi**. Eng ehtimoliy sabablar:

| Xato | Sabab |
|------|-------|
| `Server returned 403/401` | YouTube Stream key noto'g'ri yoki muddati o'tgan |
| `Connection refused` / `timed out` | Internet yoki YouTube serverga ulanib bo'lmaydi |
| `h264_nvenc init failed` | NVIDIA driverda muammo |
| `Could not find tag for codec ... in stream` | Codec moslik muammosi |

Screenshot bilan ayting — endi sababi ko'rinadi, biz darrov tuzatamiz!
