## 🎯 Stream key xatosini topdik!

### Asosiy sabab

Screenshot'dan ko'rinishicha xato edi:
```
Error opening output rtmp://a.rtmp.youtube.com/live2/rtmp://a.rtmp.youtube.com/live2: I/O error
                     └─── BAZAVIY ───┘└──── STREAM KEY (URL!) ────┘
```

Stream Key maydoniga **to'liq RTMP URL** (`rtmp://...`) kiritilgan edi. Bizning kod ham bazaviy URL'ni qo'shdi → **duplikatsiya** → FFmpeg uchun yaroqsiz URL → I/O error.

## ✅ Yechim — 4 tomondan tuzatildi

### 1. Backend avtomatik tozalaydi
Endi saqlash paytida agar key `rtmp://` yoki `rtmps://` bilan boshlansa, oxirgi `/` dan keyin nima bo'lsa shu olinadi:
```
"rtmp://a.rtmp.youtube.com/live2/abc-1234"  →  "abc-1234"
"abc-1234"                                  →  "abc-1234"
```

### 2. Bazani avtomatik tozalash (migration v2)
Eski versiyalarda noto'g'ri saqlangan stream key'lar dastur birinchi ishga tushganda **avtomatik tozalanadi**. Sizning mavjud "kirish" stream ham tuzatib qo'yiladi.

### 3. UI'da live preview
Endi Stream Key kiritsangiz, **darrov to'liq URL ko'rinadi**:
```
→ rtmp://a.rtmp.youtube.com/live2/abc•••1234
```
Foydalanuvchi nima bo'lishini ko'radi — chalkashlik yo'q.

### 4. Foydalanuvchiga aniq maslahat
- To'liq URL kiritsangiz: ⚠ ogohlantirish va avtomatik tozalash
- Faqat key kiritsangiz: 💡 normal foydalanish maslahat
- Platform bo'yicha aniq yo'l ko'rsatma (YouTube Studio → Go Live → Stream key)
