## 🎯 Stream key xatosini topdik (yana!)

### Yangi xato xabari aniq ko'rsatadi

```
rtmp://a.rtmp.youtube.com/live2/live2
                              ─────
                              Bu stream key emas!
                              "live2" — YouTube serverining yo'l qismi
```

Foydalanuvchi formada `rtmp://a.rtmp.youtube.com/live2` to'liq URL kiritgan **lekin haqiqiy key qismsiz**. Bizning sanitizer `/` dan keyingi `live2` ni olib qo'ygan — bu **server path**, key emas.

## ✅ Endi 3 ta darajada himoyalangan

### 1. Formada ⚠️ darrov ko'rinadi
Stream key kiritsangiz, **real vaqtda**:
- ✅ **Yashil** → "Stream key formati to'g'ri ko'rinmoqda"
- ❌ **Qizil** → "live2 — bu serverning yo'l qismi, stream key emas"
- URL preview rangda ko'rinadi (yashil/qizil)

### 2. Backend tekshiruvi
Saqlash paytida ham aniq xato:
- < 10 belgi → "Stream key juda qisqa..."
- Path segmenti ("live", "live2", "app", va h.k.) → "...bu serverning yo'l qismi..."

### 3. Yangi YouTube ko'rsatma karta
Formada **"📖 YouTube Stream key'ni qayerdan olish?"** tugmasi:

> 1. YouTube Studio → kirish
> 2. Create → Go live
> 3. Stream uchun ma'lumotlarni to'ldiring
> 4. "Stream settings" → "Stream key" maydonini topasiz
> 5. **COPY** tugmasini bosing (format: `xxxx-xxxx-xxxx-xxxx-xxxx`)
> 6. Bu yerga paste qiling (Ctrl+V) — **faqat key**, `rtmp://` emas

To'g'ridan to'g'ri YouTube Studio'ga link bilan.

## 🧪 Sinab ko'rish

[v0.1.9 yuklab olish](../../releases/download/v0.1.9/cam_to_you.exe).

**Hozir nima qilish kerak:**
1. Streams → "kirish" → **Edit (qalam tugmasi)**
2. Stream Key maydonini bo'shating
3. **YouTube Studio**ga o'ting, **Stream key**ni nusxalang (`xxxx-xxxx-xxxx-xxxx-xxxx` ko'rinishida)
4. Bu yerga paste qiling
5. ✅ Yashil tasdiqlash → "Saqlash"
6. **"Ishga tushirish"** → YouTube'da live ko'rinishi kerak

Asosiy farq: oldin xato YouTube'ga ulanmaganidan keyin ko'rinardi (kech), endi **kiritish vaqtidayoq** bilasiz.
